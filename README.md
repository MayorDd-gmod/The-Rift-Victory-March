# The Rift: Victory March

Документация и визуализация структуры группировки для проекта The Rift.

## О проекте
Этот репозиторий содержит статический сайт (GitHub Pages), который отображает иерархию подразделений в виде карточек. Дизайн выполнен в темной теме (Dark Mode) с адаптивной версткой.

## Структура файлов
- `index.html` — главная страница со списком подразделений.
- `style.css` — стили оформления (цвета, отступы, анимации).
- `README.md` — этот файл (описание проекта).

## Как запустить
1. Репозиторий уже настроен для GitHub Pages.
2. При внесении изменений в `index.html` или `style.css` сайт обновится автоматически после коммита.

## Лицензия
Проект находится в стадии разработки. Лицензия не определена.
